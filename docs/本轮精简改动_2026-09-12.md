# 本轮精简改动

本次沿用 pnpm 9.15.4，没有更换依赖或迁移数据库。

- 底部入口为货源、需求、发布、我的。商品搜索与全部分类从货源页进入。
- 隐藏尚未接入图片搜索的拍照入口，修正新的页面跳转方式。
- 我的需求和收藏不再重复展示；地区与联系方式收进资料设置。
- 新增我的报价，显示当前用户回应过的需求、最新商家报价与需求状态。
- 发布商品折叠规格；发布需求折叠目标价及规格；供货响应先展示价格、数量及现货状态，选填信息放到后面。
- 报价详情先展示最新商家报价，买家还价单独显示，历史按需展开。
- 联系商家为主按钮；还价、不合适和已找到货归入更多操作。
- 已找到货必须确认退出市场；接口以事务更新需求及响应，并拒绝结束后再次采纳。
- 空搜索结果可直接发布需求并带入搜索词；发布成功后进入自己的需求详情。
- 防止重复提交；修复空单价被识别为零；请求失败时保留已填内容。

验证包括微信 WXML 编译、JavaScript 页面文件及跳转检查、事件绑定检查、后端类型检查，以及真实数据库需求发布、报价、还价、用户隔离、联系、结束需求和历史保留流程。

本轮保留图片必填、三级分类、装箱数与最低起订要求。数量仍兼容原有“24件 / 2箱”等文字记录；拆分数量单位与类目规则调整留待后续集中处理。未新增内置聊天、支付、智能识图或会员业务。
