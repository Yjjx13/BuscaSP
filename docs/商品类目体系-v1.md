# BuscaSP 商品类目体系 v1

> 用途：货源发布、找货需求、搜索联想和管理后台审核。
>
> 设计原则：采用“一级类目 → 二级类目 → 三级类目”三级结构；商品发布时三级类目可选，搜索可向上聚合。

## 建议的发布规则

- 一级类目必选，二级类目必选，三级类目建议必选。
- 三级类目不匹配时，选择“其他”并填写规格；管理员随后决定是否增加新类目。
- 受监管商品（处方药、武器、烟草、成人用品、金融服务等）不开放普通发布，后续以独立合规规则处理。
- 搜索联想同时使用：类目名称、三级类目别名、商品标题、规格和管理员维护的关键词。
