# BuscaSP v0.2.0 — 找货与供货响应 MVP

发布日期：2026-08-27

本版本完成了本地商品市场和找货需求的基础业务闭环，可用于微信开发者工具中的本地演示与小范围功能测试。

## 已完成

### 商品货源

- 商品图片、标题、三级分类、单价、装箱数、最低起订箱数和规格发布。
- 首页双列货源展示、商品详情、相似商品推荐及商家地区展示。
- 全局模糊搜索、关键词推荐、最多 15 条搜索历史及一键清除。
- 分类页三级类目筛选和类目内搜索。
- 我的商品查询、分页、编辑、换图、上下架、软删除、15 天恢复及自动清理。
- 商品收藏和联系方式获取。

### 找货需求

- 使用参考图片、需求说明、数量、规格、目标价和有效期发布找货需求。
- 需求市场按最新时间展示并支持模糊搜索。
- 已找到、已关闭或已过期的需求不再进入公开市场。
- 我的找货需求、响应数量和找货方未读提醒。

### 供货响应与议价

- 商家针对需求提交供货响应。
- 商品单价、可供数量和现货或预售状态为必填项。
- 预售报价必须填写预计可交货日期。
- 颜色、型号、包装和交货条件可作为选填说明。
- 可选关联商家自己已经上架的商品，并在报价中展示商品图片、标题和规格。
- 支持找货方与供货商多轮报价，每轮价格、数量、状态、交期、说明和时间独立保存。
- 找货方可以联系商家、标记不合适或采纳货源。
- 采纳后需求变为已找到货并停止接受新报价。

### 用户、地区与后台

- 微信登录接口及本地开发登录回退。
- 用户联系方式加密保存。
- São Paulo 地区表及 Centro、Brás 等地区展示。
- 管理后台的用户、商品、需求和基础数据管理。
- PostgreSQL 数据库存储、Docker 本地运行及一键启动脚本。

## 数据库升级

- `012_wanted_response_flow.sql`：响应报价、数量、未读状态和联系方式查看记录。
- `013_wanted_offer_rounds.sql`：多轮报价历史。
- `014_supply_availability.sql`：现货、预售和预计可交货日期。

## 本版本暂未包含

- 采纳后的独立成交记录和采购完成状态。
- 其他报价自动标记为未采纳，以及重新找货。
- 商家侧统一的“我的供货响应”和还价未读提醒。
- WhatsApp 一键联系。
- 完整中文、葡萄牙语切换。
- 公网 HTTPS、正式部署及真实微信 AppSecret 配置。
- 内置聊天、支付、物流和平台担保交易。

## 验证结果

- API TypeScript 类型检查通过。
- 小程序核心 JavaScript 页面语法检查通过。
- 已完成现货报价、预售报价、关联商品、联系方式和多轮议价接口联调。
- 本地 PostgreSQL 数据迁移已应用，原有商品和找货数据保留。
